## 自動・内容検証

教材取り込み前検証：13記事＋1語彙ユニット、0エラー。語彙の未収録語警告は4件で、確認理由を各教材と `stage7-material-validation.json` に記録。
既存の麹・エウロパ教材、新規の文化統計・粒子検出器に専門語・複合語が含まれる。未収録語は上位レベル語と別集計しており、未収録を易しい語として扱っていない。レベル表示は編集上の目安で、公式のCEFR認定ではない。

自動テスト114件通過。採点の選択肢ID、モード・スコア、同期、取得失敗と再試行、利用者切替中の遅延取得、数値・固有名詞の訳対応、訳の開閉・初期化、英語以外の選択除外を検証。

公開時のCIでWindowsのCRLF改行とGitのLF改行によるハッシュ差を検出し、取り込み検証の `--write` で原教材の改行もLFに揃えてからハッシュを生成するよう修正。公開ファイルとローカル表示の照合を一致させた。

独立レビューの指摘を修正：取得失敗時の誤った0件表示、初期目次ハッシュ失敗が保存語0件で解除される問題、補足出典の公開日不明、equipmentの曖昧な誤答、performの訳、experimental designの例文。
独立レビューで出典の人数・対象範囲・計画と実績、訳の数字・否定・推定を照合。最終の追加再監査はエージェント利用上限で完了できなかったため、主担当が指摘修正と114件の最終検証を確認。利用者本人による全教材・コロケーションの最終レビューは未実施。使い方の状態は未確認のまま保持。

写真はUnsplash無料素材を使用。条件・撮影者は教材JSONに保持し、記事写真下だけにクレジット。帰属は通常のUnsplash Licenseでは任意だが要件に従って表示。記事中の出来事そのものの写真であるとは扱わない。
