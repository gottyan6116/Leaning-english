# 第3段階 骨格・ホーム 検証結果

検証日: 2026-10-04（日本時間）
状態: ローカル実装・動作確認済み。

## 変更
- 1024px未満は5項目の下部タブバー（56px+safe-area）、1024px以上は176pxの左ナビ。
- 主本文720px、記事本文680px。既存色値/フォント値を保持しCSS変数化。
- 青ヒーロー・固定連続日数・固定時間をホームから除去。復習件数と唯一の主要CTAへ。
- リング/今週時間はDOM生成しない。日週目標は保存のみ。
- C1①は承認済みdraft10語をそのまま使用。残り90語は作成しない。
- 最新誤答/SKIPと保存済み未回答語を復習対象化。未学習ユニットは対象化しない。
- ユニット成績は完成した10問の現在モードのベスト。短いretry/中断は対象外。
- settings/quiz menuは同じQuizStoreを参照。新しい保存キーだけ追加。既存回答/保存IDを保持。
- 公開条件を満たさない記事はホーム非表示。ノート件数は実保存だけ。
- 保存・解除を記事/セッションで共有。書込失敗の巻き戻し、結果画面の保存再試行を追加。
