# 第12段階：ホーム画面の刷新

## 目的
ホームを、「今日やること」「学習の進捗」「継続」が一目で分かる画面にする。レイアウト・余白・角丸・文字の大きさ・色の使い方は添付画像に忠実に合わせる。ただし、表示する数字はすべて実データから算出し、架空の数字やまだない機能を表示しない（このルールは画像より優先する）。

（添付画像：1枚目＝PC、2枚目＝スマホ。ユーザーが会話に添付した画像で、リポジトリには含まれない）

## 0. 画像から変更する点（必ず守る）
- 「今週の学習時間」は、学習時間の計測が未実装のため、「今週の回答数」に置き換える。棒グラフも日ごとの回答数にする。学習時間の計測を実装したら差し替える前提で、表示部分は数値の種類を切り替えられる作りにする
- 「リスニング時間」の小カードは「組み合わせ」（今週回答した組み合わせの数）に置き換える
- 「リスニング練習」のタスクは「組み合わせの復習」に置き換える
- 「最近保存した記事」は「新着の記事」に置き換える
- 挨拶の下のキャッチコピー（今日も一歩ずつ…）は置かない
- スマホの右上のベルアイコンは置かない
- 画像の「基礎単語 C1①」は画像上の仮の文字。実際には後述のルールで決まるセット名を表示する

## 1. design-rules.md の更新
以下を追記する。
- 主役色 #ff3366 の使用箇所に「達成の表示」を追加する。対象は、ホームの今週の棒グラフの今日の棒、カレンダーの今日の丸と学習した日の点、継続記録のチェック、今日の学習の完了チェックのみ
- ホームの「今日の学習」と「最近の学習」のアイコンに限り、学習の種類ごとの色を使ってよい。単語＝ピンク系、組み合わせ＝紫系、記事＝緑系。design-tokens.css にトークンとして追加する（例：--color-kind-vocab-bg / -fg、--color-kind-colloc-bg / -fg、--color-kind-article-bg / -fg）。紫系は淡い背景 #EEF0FF・アイコン #5B63D6 程度、緑系は既存の正解色の系統を使う。この3色を他の画面に広げない

## 2. PCのレイアウト（1024px以上）
- 左ナビは既存のまま。ナビの最下部は、アカウントアイコン＋表示名（未設定ならメールアドレスの@より前は使わず「アカウント」）＋「›」
- 本文は2列。左列（主列）と右列（補助列）の幅の比はおよそ 5:4、列の間隔24px。全体の最大幅1280px
- 左列：上から「日付・挨拶」「今日の学習」「最近の学習」
- 右列：上から「週のカレンダー」「学習の進捗」「継続記録」「新着の記事」
- カードは白い面、角丸20px、既存の面の影トークン、内側の余白24px、カード同士の縦の間隔20px。カードに厚み（下側の影）は付けない（押せる要素は内部の行やボタン）

## 3. スマホのレイアウト（1023px以下）
- 1列。上から「挨拶（2行：おはようございます／Takaさん）」「今日の学習」「学習の進捗」「継続記録」「最近の学習」「新着の記事」
- 週のカレンダーはスマホでは表示しない
- 「今日の学習」のカードは、見出し部分の背景を淡いピンク（primary-soft）にする（2枚目の画像のとおり）
- 「学習の進捗」は、左に数値、右に棒グラフを並べ、その下に小カード3つを横並び
- 下部タブは既存の5項目のまま

## 4. 各ブロックの仕様

### 日付・挨拶
- 日付：「10月7日（水）」の形式、13px、薄い文字色
- 挨拶：28px（スマホ22px）太字。日本時間で4〜10時「おはようございます」、10〜18時「こんにちは」、それ以外「こんばんは」。表示名があれば「、Takaさん」を付ける（スマホは改行して2行目に「Takaさん」）
- 表示名：学習設定に「表示名」の入力欄を追加し、端末内に保存する（同期はしない。データベースの変更はしない）

### 今日の学習
- 見出し：アイコン＋「今日の学習」、右端に「0 / 3 完了」
- タスクを3行。各行：左に完了チェックの丸（未完了は灰色の線の丸、完了は主役色の塗り＋白いチェック）、種類の色のアイコン（56px角、角丸16px、淡い背景に濃いアイコン）、タイトル（16px太字）、補足（13px、「10問・約5分」など）、右端に「›」。行全体がタップ領域で、押すとそのタスクを開始する
- タスクの決め方（毎日、日本時間で計算）
  1. 単語：今日の復習が1件以上あれば「今日の復習」（補足：n語・約n分）。なければ、未クリアの最初のセット（例：「基礎単語①」、補足：10問・約5分）
  2. 組み合わせ：組み合わせの復習が1件以上あれば「組み合わせの復習」（補足：n件・約n分）。なければ「組み合わせクイズ」（補足：10問・約5分）
  3. 記事：まだ読了していない記事のうち、最新のもの（タイトル：「記事を読む」、補足：記事タイトル・約n分）。全記事を読了済みなら、最新の記事を「記事を読み直す」として表示
- 完了の判定：その日に、該当する種類のセッションを最後まで終えた（または記事を読了した）ら完了
- 所要時間の目安は1問30秒で計算する
- カード下部の主要ボタン：「▶ 最初のタスクをはじめる」（未完了の最初のタスクを開始）。途中まで完了していれば「▶ 次のタスクをはじめる」。全部完了したら、ボタンの代わりに「今日の学習は完了です」と表示し、主要ボタンは置かない

### 最近の学習
- 見出し：時計アイコン＋「最近の学習」、右に「すべて見る ›」（記録の画面へ）
- 直近の学習を3件。種類のアイコン（44px）、タイトル（セット名・記事名など）、補足（「単語・30分前」）、右に「›」
- 学習の記録がなければ、このカードは表示しない

### 週のカレンダー（PCのみ）
- 見出し行：「‹ 2026年10月 ›」。矢印で1週間ずつ移動
- 月〜日の7日を1行。今日は主役色の丸に白い数字。学習した日（回答または記事の読了が1件以上ある日）は、数字の下に主役色の小さな点

### 学習の進捗
- 見出し：アイコン＋「学習の進捗」、右に「詳細 ›」（記録の画面へ）
- 左：「今週の回答数」（13px）と、数値（32px太字。単位「問」は小さく）
- 右：月〜日の7本の棒グラフ。今日の棒は主役色、それ以外は薄い灰色。棒の角は上だけ丸める。今日の曜日ラベルは主役色。データが0の日も、高さ最小の棒を表示
- 下：小カード3つ横並び（薄い枠、角丸14px）。「学習した単語 n語」（今週回答した単語の異なり数）、「読んだ記事 n本」（今週読了した記事数）、「組み合わせ n件」（今週回答した組み合わせの異なり数）
- 今週の区切りは日本時間の月曜始まり

### 継続記録
- 見出し：炎のアイコン＋「継続記録」、右に「›」（記録の画面へ）
- 「n日連続」（数字は大きく太字）。今日か昨日まで、学習した日が途切れずに続いた日数。今日まだ学習していなくても、昨日まで続いていれば連続を維持する
- 直近7日のチェック。学習した日は主役色の丸に白いチェック、していない日は灰色の線の丸。下に日付（10/1の形式）
- 学習した日がまだ1日もなければ「今日から始めましょう」とだけ表示

### 新着の記事
- 見出し：アイコン＋「新着の記事」、右に「すべて見る ›」（記事一覧へ）
- 新しい順に2件。左に写真（角丸10px、80×64px程度）、右にタイトル（2行まで）、下にレベルの札・分野・元記事の日付

## 5. 状態とアクセシビリティ
- 初めて使う利用者（記録が0件）でも、穴や空の枠が出ないこと
- 未ログイン（ゲスト）でも、端末内のデータで同じように表示する
- 全ての行・ボタンはキーボードで操作でき、フォーカスが見える
- 色だけで状態を伝えない（完了はチェックの形でも示す）
- 数字の算出ロジックは、表示部分と分けたモジュールにし、テストを書く（連続日数、週の区切り、タスクの決定と完了判定、日本時間の日付の境界）

## 6. 守ること
- 既存の design-rules.md、design-tokens.css、CLAUDE.md のルール（今回の追記を除く）
- 既存のデータ、同期、他の画面の動作を壊さない
- データベースは変更しない
- スコープ外：学習時間の計測、記録画面の作り直し、リスニング機能

## 進め方（「止まる」とある工程では必ず止まること）
1. 仕様の要約、各ブロックの数字の算出方法（どのデータから、どう計算するか）、design-rules.md と design-tokens.css への追記案、画像からの変更点の一覧を出力して止まる
2. 承認後に実装する。実装中は、自分で390px・1280pxのスクリーンショットを撮って添付画像と見比べ、余白・大きさ・配置のずれを直すこと。スクリーンショットの提出は不要
3. テストを実行し、変更点、添付画像との差（意図的に変えた点と、再現しきれなかった点）、チェックリストの評価を報告して止まる
4. 承認後、push して公開版への反映を確認する

## 受入チェックリスト
- [ ] PCで2列、スマホで1列の構成が、添付画像の配置と一致している
- [ ] 表示されている数字がすべて実データから算出されている（固定値がない）
- [ ] 今日の学習の3タスクが、データに応じて正しく決まり、完了の判定が正しい
- [ ] 連続日数と、直近7日・カレンダーの学習日の表示が一致している
- [ ] 記録が0件の利用者で、穴や空の枠が出ない
- [ ] 主役色と種類の色が、design-rules.md に追記した範囲だけで使われている
- [ ] キャッチコピー、ベル、リスニング関連の表示がない
- [ ] 学習設定で表示名を設定でき、挨拶に反映される
- [ ] 算出ロジックのテストが追加され、既存のテストがすべて通る
