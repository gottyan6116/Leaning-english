# ログイン時の自動統合とUUID照合の修正

確認日：2026-10-05

## 変更

- ログイン時に未統合のゲスト記録・旧形式の記録を本人の端末保存とoutboxへ自動統合する。確認画面、取り込み導線、件数、完了トーストを削除した。
- 記録IDと更新版に対する端末共通の所有者台帳を残し、別アカウントへ既存記録を再統合しない。ローカル保存失敗時も元の所有者だけが再試行できる。
- 統合済みのゲスト記録は通常表示から除外し、本人の内部バックアップに保持する。旧キーは残す。JSON書き出しには内部移行情報を含めない。
- UUID値は引用符なしで照合する。対象IDはテーブルごとにinフィルタでまとめ、100件を超える場合のみ分割する。
- POST成功と確認GET成功を分離した。GET失敗で送信済みデータを失敗に戻さない。未送信は通常同期で再送する。恒久的な送信エラーは既存の送信できないデータに保持する。
- 遅れて到着する記事語彙、旧形式の記事保存番号、ログアウト後の新しいゲスト学習にも対応した。
- design-rules.md、同期設計書、設定手順書を更新した。DB変更はない。

## 自動検証

Nodeテスト124件成功、失敗0件。次を含む。

- ゲスト回答7件と未設定目標をログイン時に自動統合。UUID照合は1回のin問い合わせ。
- ログアウト後の新しい回答を再統合しても以前の回答は重複しない。
- 別アカウントには新しいゲスト記録だけを統合する。
- POST成功・重複再送成功の後に照合GETが400でも、送信失敗やblockedへ移さない。
- オフラインで復元したログイン状態でも端末内統合を完了する。
- 古い成功記録、保存語の遅延解決、旧キーからの復元、明示的な再保存、内部バックアップの書き出し除外。
- 通常同期、認証、端末別データ分離、記事・クイズの既存回帰テスト。
