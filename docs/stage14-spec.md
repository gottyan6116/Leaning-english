# 第14段階：単語の練習中に組み合わせを登録できるようにする

## 目的
単語の練習の中で、その語の組み合わせ（コロケーション）に触れ、復習の対象として登録できるようにする。あわせて、組み合わせクイズの答えが見えてしまう不具合を直す。

## 1. 不具合の修正（最優先）
- 組み合わせクイズの穴埋め（例：「___ practitioners」）で、カードの例文に正解の語がそのまま表示されている（例：「The research team will consult practitioners.」）
- 出題中は、例文の正解の語も空欄（___）にする。回答後の解説シートでは、完全な例文を表示する
- 他の出題形式（定義→英など）でも、出題中に正解が見える箇所がないかを全形式で点検し、あれば同じく直す。点検結果を報告すること

## 2. 単語の練習中の組み合わせ表示と登録
- 解説シート（誤答・SKIP・時間切れ、自動送りオフで正解したとき）：正解の語と例文の下に「よく一緒に使う表現」を最大3つ表示する。各組み合わせに、意味（1行）と、しおりのボタン（未登録は線、登録済みは塗りつぶし）
- 結果画面：「この回の単語の表現」というセクションを追加し、今回出題した語ごとに、組み合わせを最大3つ表示する。各組み合わせにしおりのボタン。組み合わせのない語は表示しない。セクション全体で組み合わせが0件なら、セクション自体を表示しない
- 出題中（回答前）は、組み合わせを表示しない（答えのヒントになるため）
- 登録した組み合わせは、既存の「組み合わせ」タブに表示され、組み合わせの復習の対象になる。登録だけでまだ解いていない組み合わせも、組み合わせの復習に含める（保存した単語と同じ扱い）
- 登録・解除は、既存の組み合わせの保存と同じ仕組み・同じデータで行う（第8段階の保存と区別しない）
- データベースの変更が必要な場合は、SQLを作って止まること。不要であることを確認できればその旨を報告する

## 3. 単語帳の語への組み合わせの追加
- 対象：ビジネス単語、アドバンス単語、超アドバンス単語の各①〜③（90語）。基礎・日常と④〜⑥は今回は対象外
- 1語につき3つ。第8段階と同じデータ形式（不変のID、元の語のID、組み合わせ、型、日本語の意味、ニュアンスの違い、オリジナルの例文、状態 unverified）
- 単語帳で出題している意味（testedSense）に合った組み合わせにする
- 辞書のコロケーション例や例文を転載しない
- 穴埋めクイズの誤答の条件は第8段階と同じ（文法的には入りうるが、その名詞と一般的に組み合わない語）

## 4. ニュアンスの説明の品質
- 現在の組み合わせ（記事の65語・195件）の「ニュアンスの違い」に、日本語の意味を言い換えただけの説明（例：「『実務家に意見を聞く』という場面で用いる組み合わせ。」）が入っている
- ニュアンスの説明は、「似た表現との違い」「使う場面（改まった場面か、日常か）」「よく一緒に来る語」のいずれかの情報を含めること。例：「consult は専門家に意見や助言を求めるときに使う。ask より改まった言い方で、相手が専門家であることを含意する」
- 新しく作る90語分は、最初からこの基準で書く
- 既存の195件のうち、言い換えだけの説明を自動で検出する方法を提案し、該当件数を報告すること。書き直しは今回は行わない（次の段階で扱う）

## 5. 守ること
- design-rules.md、design-tokens.css、CLAUDE.md のルールに従う
- 既存の保存・復習・同期・クイズの動作を壊さない

## 進め方（「止まる」とある工程では必ず止まること）
1. 不具合の原因と、全形式の点検結果、組み合わせの表示位置と登録の仕組み、データベースの変更の要否、言い換えの説明の検出方法を出力して止まる
2. 承認後、不具合の修正と、表示・登録の機能を実装する
3. 90語分の組み合わせを作り、ビジネス①の10語分（30件）を一覧にして止まる（内容レビューのため。語、組み合わせ、型、意味、ニュアンス、例文、穴埋めの誤答）
4. 承認後、残りを作成し、テストを実行して、変更点とチェックリストの評価を報告して止まる
5. 承認後、push して公開版への反映を確認する

## 受入チェックリスト
- [ ] 組み合わせクイズの出題中に、例文から正解が見えない
- [ ] 全出題形式で、出題中に正解が見える箇所がない
- [ ] 解説シートと結果画面から、組み合わせを登録・解除できる
- [ ] 出題中には組み合わせが表示されない
- [ ] 登録した組み合わせが「組み合わせ」タブと組み合わせの復習に入る
- [ ] ビジネス・アドバンス・超アドバンスの①〜③（90語）に組み合わせが3つずつある
- [ ] 新しい組み合わせのニュアンスが、言い換えではなく違いや使う場面を説明している
- [ ] 既存の言い換えの説明の該当件数が報告されている
- [ ] 既存のテストがすべて通る
