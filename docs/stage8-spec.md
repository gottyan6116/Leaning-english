# 第8段階：コロケーション中心の学習

## 目的
単語帳との差別化として、学習の単位を「語」から「一緒に使われる表現（コロケーション）」に変える。例えば decision なら、make / reach / reverse a decision、a tough / controversial decision を、それぞれ別の学習項目として覚えられるようにする。AIは使わない（AI添削は第9段階）。スクリーンショットの提出は不要。変更点、テスト結果、チェックリストの評価だけを報告すること。

## 1. データ
- コロケーションを独立した学習項目にする。各項目：不変のID、元の語のID、組み合わせ（例：reverse a decision）、型（動詞＋名詞／形容詞＋名詞／名詞＋前置詞／その他）、日本語の意味、ニュアンスの違い、オリジナルの例文、使わない組み合わせの例（任意）、状態（unverified／verified）
- 既存の記事の重要語彙65語の usage データを、この形式に移行する。C1①の10語は対象外（作り直しの工程で扱う）
- 不変のIDは、既存の usage から移行した後も変わらないようにする
- 辞書のコロケーション例や例文を転載しない
- unverified も出題してよい。その場合は、画面に「確認中」と控えめに表示する（文字だけ。ピル型バッジは使わない）。verified への変更はユーザーが行うので、勝手に変更しない

## 2. 回答ログ（データベースの変更）
- answer_logs の kind は現在 vocabulary と comprehension のみを受け付ける。組み合わせクイズを記録するため、collocation を追加するマイグレーションのSQLを作成する
- 適用済みのマイグレーションの中身は変更せず、新しいファイルとして作る
- SQLを作成したら止まって、適用をユーザーに依頼すること（ユーザー側のClaudeがSupabaseコネクタで適用する）。適用時に採番された番号にファイル名を合わせる
- 端末側では、適用前に組み合わせクイズの回答が送信できない状態でも、既存の「送信不能データ」の扱いで安全に保持されることを確認する

## 3. 語の詳細画面
- 見出し語と意味の下に「よく一緒に使う表現」を主役として置く
- 型ごとにまとめ、各組み合わせに：意味、ニュアンスの違い、例文、保存（しおり）
- 保存の単位は組み合わせ。単語一覧でも、保存した組み合わせを見られるようにする（既存の状態別セクションと3点ゲージの方式に従う）

## 4. 組み合わせクイズ（第1段階のセッションを再利用）
- 穴埋め：「___ a decision」に入る語を4択で選ぶ。例文を添える
  - 誤答は、文法的には入りうるが、その名詞と一般的に組み合わない語から選ぶ。正解と同じくらい自然に使える語を誤答にしない
- 誤用の見分け：4つの組み合わせのうち、使わないものを選ぶ
  - 出題は、データに「使わない組み合わせの例」が明示的に登録されている項目だけから行う。登録がない項目では、この形式を出題しない
- 選択肢の位置は毎回ランダム、採点は選択肢のIDで行う（既存方針どおり）
- おまかせ復習の対象に、誤答した組み合わせを含める

## 5. 守ること
- design-rules.md、design-tokens.css、CLAUDE.md のルールに従う
- 既存の端末内データ、同期の仕組み、記事・単語の機能を壊さない
- スコープ外：AI添削、Cloudflareの設定、学習時間の計測、C1①の作り直し

## 進め方
1. データ形式、移行方法、画面の構成、マイグレーションのSQL案を出力して止まる
2. 承認後、マイグレーションのSQLファイルを作成して止まる（ユーザー側で適用）
3. 適用の報告を受けたら実装する。移行後のコロケーションは、ユーザーが確認できるよう1つの一覧ファイル（語、組み合わせ、型、意味、例文、使わない組み合わせの例）にまとめて提示する
4. テストを実行し、変更点とチェックリストの評価を報告する

## 受入チェックリスト
- [ ] 65語の usage が新しい形式に移行され、IDが安定している
- [ ] 語の詳細画面で、組み合わせが型ごとに主役として表示される
- [ ] 組み合わせ単位で保存でき、単語一覧に表示される
- [ ] 穴埋めクイズが動き、誤答が復習対象に入る
- [ ] 誤用の見分けは、使わない組み合わせの例が登録された項目だけから出題される
- [ ] unverified の組み合わせに「確認中」が表示される
- [ ] 組み合わせクイズの回答が、マイグレーション適用後に同期される
- [ ] 既存のテストがすべて通る
