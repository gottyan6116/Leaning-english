# 共通デザインルール

今後、すべての段階の作業開始時に、このファイルを必ず読む。

- 英字の小見出し（例：YOUR WORDS、READ & DISCOVER）を置かない。
- キャッチコピー・スローガン・情緒的な説明文を置かない（例：「英語で、世界を広げる。」）。
- デモ・サンプル・未接続などの注釈を置かない。
- 偽の表紙画像（文字だけの装飾サムネイル）を作らない。
- 状態表示に「淡い色地＋同系色文字のピル型バッジ」を使わない。状態はセクション見出し・アイコン・ゲージで表す。
- 絞り込みで表示中の状態を、各行で繰り返し表示しない。
- 主役色 #ff3366 は、主要ボタン・進捗バー・選択中のナビの3か所のみ。状態表示・バッジ・装飾には使わない。
- 1画面に主要ボタンは1つまで。
- 第4段階のトークンと質感ルールに従う。

## 第4段階のトークンと質感

- 色・文字・角丸・影・動きは `design-tokens.css` の変数を使う。コンポーネント内に色を直書きしない。
- フォントの太さは400と700。主要ボタンのラベルは18px以上・太字。
- 主要ボタンの厚みは下側4px。押下時は4px下がり、厚みを0にする。
- 選択肢・副ボタンは白地＋1px枠線、下側2px。押下時は2px下がる。
- 問題カード・ホームの復習面・リストに厚みを付けない。面の影は `--shadow-surface` の1種類のみ。
- カードの角丸16px、ボタンと選択肢はピル型、入力欄12px。
- 動きは100〜200ms・ease-out。押下の沈み込みは80ms。動きを減らす設定では揺れと沈み込みを無効化する。
- グラデーション、半透明の面、ぼかし、ニューモーフィズム、指定外の影は禁止。
- クイズの正誤は色だけで表さず、誤答の×・4px/200ms/1回の揺れ・正解のチェックを組み合わせる。

## 単語一覧の状態表示

- 状態は復習予定→学習中→未学習→定着のセクションで表示し、0件のセクションは非表示。
- 見出しは16px・太さ700・通常の文字色。各セクションは白いグループリストと細い行区切り。
- 行の右端は直径6pxの点3つ、間隔4px。空の点は `--color-border`、埋める点は `--color-correct`。
- 未学習・復習予定は0点、学習中は1点、定着は3点。状態名をゲージのaria-labelに付ける。
- 詳細を開く行には›を残す。開かない行には付けない。
- 復習ボタンは、対象がある場合だけ復習予定セクションの直後に置く。
- 状態の算出・保存・同期の仕様は、見た目の改修で変更しない。

## 第6.5段階：ログインとアカウント

- グラスモーフィズムはログイン画面に限り使用してよい。アプリ本体では禁止を維持する。
- ログイン画面の背景だけに、グラデーションと静止したぼかしによる色のにじみを使用してよい。主役色を背景へ使う例外もこの画面に限る。アプリ本体ではグラデーションは禁止。
- ログインのすりガラス・背景色は design-tokens.css の専用トークンを使う。非対応環境・prefers-reduced-transparency: reduce では不透明な白いカードにする。
- 内部の件数内訳、秒単位の時刻、保存形式の名前など、開発・検証用の情報を通常画面に表示しない。
- 未実装の機能に関する設定項目を表示しない。日・週目標は非表示とし、保存済みの値は保持する。
- 同期日時、再同期、JSON書き出しはデータの管理に置く。通常のアカウント画面では同期異常・未送信だけを表示する。
- 教材の出典・ライセンスは「このアプリについて」に集約する。
- ログイン時のゲスト記録（旧形式を含む）のアカウントへの統合は自動で行い、確認画面・判断用のボタン・件数表示・完了トーストを表示しない。データの管理にも取り込みの導線を置かない。
- 統合済み記録の端末内バックアップと重複防止は内部で扱い、利用者には表示しない。送信できないデータの確認・破棄はデータの管理にのみ置く。


## 第7段階：記事の写真とレベル属性

- 写真の上に文字を重ねる場合に限り、写真の下部約45%に、下端rgba(0,0,0,0.6)から上端透明へ自然に薄くなる幕を使用してよい。不透明な帯や境界線を作らない。それ以外のグラデーション禁止は、ログイン画面の既存例外を除き維持する。
- 写真の上に重ねるタイトル・段階名は白とし、文字の影0 1px 3px rgba(0,0,0,0.6)と下から薄くなる幕を専用CSSトークンで管理する。レベルの白い四角と分野の札は維持する。大小のタイルで幕の濃さを変えない。全面の暗い幕・アプリ本体のぼかしには広げない。
- レベル表示は状態バッジではなく記事の属性。A2／B1／B2／C1などの小さな枠付きの短いラベルとし、レベルごとの色分けはしない。ピル型の状態バッジにはしない。

## 記事一覧の例外

- 記事一覧のモザイクと分野別の棚に限り、写真とカードの角丸を0、タイル間隔を0〜2pxとしてよい。
- 同範囲ではカードの下側の厚みを付けない。ホバー時の写真拡大1.03倍・200msと暗転、フォーカス時の明確な枠線で押せることを示す。prefers-reduced-motionでは拡大しない。
- NEW・レベル・分野は、角のない小さい四角の札を使ってよい。状態表示のピル型バッジ禁止は維持する。
- 写真上の文字は写真へ直接重ね、背景帯を付けない。下から薄くなる幕と文字の影は専用トークンを使う。注目モザイクはタイトル・レベルと段階名・分野・NEWだけを表示し、元記事の日付と読む時間は棚と結果一覧にのみ残す。その他の画面の配色・質感・構造のルールは変えない。

## 第12段階：ホーム画面

- 主役色 #ff3366 は、「達成の表示」にも使ってよい。対象は、ホームの今週の棒グラフの今日の棒と今日の曜日ラベル、カレンダーの今日の丸と学習した日の点、継続記録のチェック、今日の学習の完了チェックのみ。それ以外に広げない。
- ホームの「今日の学習」と「最近の学習」のアイコンに限り、学習の種類ごとの色を使ってよい。単語＝ピンク系、組み合わせ＝紫系、記事＝緑系。専用トークン `--color-kind-*` を使い、他の画面には広げない。
- ホームのカードは白い面、角丸20px（`--radius-home-card`）、面の影は `--shadow-surface` の1種類、厚みなし。内側の小カードは `--radius-tile`、記事の写真は `--radius-thumb`。
- ホームに表示する数字はすべて実データから算出する。固定値・架空の数字・未実装の機能の表示を置かない。キャッチコピー、ベル、リスニング関連の表示を置かない。
- 完了や学習した日は、色だけでなくチェックや点の形でも示す。

## 第15段階：記録画面（学習時間）

- 主役色 #ff3366 は、「達成の表示」として、記録画面のヒートマップ（主役色の濃淡5段階。`--color-heat-1`〜`--color-heat-5`）と、節目までの進捗のバーにも使ってよい。0分の日は薄い灰色（`--color-heat-0`）。それ以外に広げない。
- 記録画面の積み上げ棒グラフと種類別の内訳は、ホームの種類の色（単語＝ピンク系、組み合わせ＝紫系、記事＝緑系。`--color-kind-*`）を使ってよい。アプリ外の学習は灰色系（`--color-kind-outside-*`）で区別する。
- 記録画面の数字はすべて、計測した区間と手動の記録から算出する。固定値・サンプル値を置かない。英字の小見出しとキャッチコピーを置かない。
- 学習時間を英語力の上達として表現しない。学習しなかった日や先週より少ない週を責める表現（サボり、など）を使わない。比較は「先週の同じ期間より +48分」「先週の同じ期間より 20分少なめ」の形にする。
- 記録が0件の利用者には、空の枠や0だらけの表示を出さず、「学習すると、ここに記録が積み上がります」の1行とホームへの導線だけを置く。

## 第16段階：表現ページ

- ナビは「単語」「記事」「表現」の3つ（リスニングの画面は外した。データ・検証・テストは残す）。
- 表現の種類色は橙系（`--color-kind-expr-bg` / `--color-kind-expr-fg`）。ホームの種類の色（単語＝ピンク系、組み合わせ＝紫系、記事＝緑系）に続く4つ目として、記録画面の内訳と週の積み上げ棒にだけ使う。
- 機能ページは、丁寧さ×強さの表（スマホは丁寧さごとの縦リスト）。確認中（unverified）の表現は色ではなく「確認中」の文字で示す。
- 並べ替えの問題は、スマホはタップ順に番号を付け、PCはドラッグと↑↓ボタン・キーボード（ArrowUp/ArrowDown）で操作できる。
- 「引き出し n / m」は定着（直近2回正解）した表現の数。進捗を責める表現は使わない。
