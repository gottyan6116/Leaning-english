# 単語一覧の状態表示：確認結果

確認日：2026-10-04。既存の状態算出・データ保存・同期は変更していない。

## 変更箇所

- 保存した語タブの横フィルタと状態バッジを削除。復習予定→学習中→未学習→定着のセクションに変更し、0件は表示しない。
- 見出しは16px・700・通常の文字色。各セクションは白い面と行区切りを維持。
- 3点ゲージは直径6px・間隔4px。未学習と復習予定は0点、学習中は1点、定着は3点。空はborder、埋める点はcorrect。状態名のaria-label付き。
- 各行は詳細画面を開くため、右端の›を維持。未保存のユニット復習語からも詳細を開けることを実操作で確認。
- 復習ボタンは復習予定セクションの直後にのみ配置。対象0件では表示しない。
- 上級語彙集のC1①行から状態文字を削除し、「ベスト n/10」と10/10時のチェックアイコンに統一。
- バッジ専用のlearning-softとlearning-textを削除。primary-soft・correct-soft・correct-text等はナビやクイズでも使用するため維持し、単語の状態バッジへの使用を削除。
- docs/design-rules.mdを作成。AGENTS.mdにも全作業開始時の必読を指定。

## 状態と件数

前回の定義を維持。復習予定は現在のモードで直近の回答が誤答/SKIPの語（保存有無・出どころ不問）と、未回答の保存語。直近正解は除外。ホームと同じ復習対象を使用する。その他のセクションは保存語を既存の回答ログによる状態で分類する。
