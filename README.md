# English Notes

B2〜C1向けの個人用英語学習アプリ。現時点の成果物は、ブラウザで操作できるUIプロトタイプです。

## 画面

- ホーム：今日の復習、教材棚、学習目標。
- 単語・表現：保存一覧、手入力、日本語・英語の4択。
- 記事：ジャンル選択、本文、出典リンク、表現の保存。
- リスニング：ブラウザ音声読み上げ、速度選択、問題・自由練習。
- 学習記録：今週・今月・先月・累計、先月同期間との比較、継続日数とカレンダー。

## ローカルで確認

Python 3がある環境で、リポジトリのルートから実行します。

```sh
python -m http.server 8767 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8767/` を開きます。学習記録は `/#records` で直接開けます。ビルドや依存パッケージのインストールは不要です。

## 現在の状態

学習記録と語彙の変更は画面内の状態です。再読み込みで初期状態へ戻ります。Googleログイン、Supabaseによる同期・永続保存、Cloudflareへの公開、教材の予約配信は未実装です。

学習記録の初期データは2026年10月3日時点の表示確認用です。掲載教材は辞書の語義に基づく自作の短い表現解説で、出典は本文に表示しています。事実に基づくニュース教材の登録は今後の工程です。

音声の声質と利用可否はブラウザ・OSに依存します。日本語フォントはGoogle Fontsから読み込み、利用できない場合は端末のフォントへ切り替わります。

合意したアプリ要件は [docs/requirements.md](docs/requirements.md) を参照してください。
