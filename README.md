# English Notes

B2〜C1向けの個人用英語学習アプリ。現時点の成果物は、ブラウザで操作できるUIプロトタイプです。

## 画面

- ホーム：今日の復習、教材棚、学習目標。
- 単語・表現：保存一覧、手入力。ホームから全画面の日本語・英語4択セッションを開始。
- 記事：ジャンル選択、本文、出典リンク、表現の保存。
- リスニング：ブラウザ音声読み上げ、速度選択、問題・自由練習。
- 学習記録：今週・今月・先月・累計、先月同期間との比較、継続日数とカレンダー。

## ローカルで確認

Python 3がある環境で、リポジトリのルートから実行します。

```sh
python -m http.server 8767 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8767/` を開きます。学習記録は `/#records` で直接開けます。ビルドや依存パッケージのインストールは不要です。

## 現在の状態

既存の学習記録と語彙一覧の変更は画面内の状態です。クイズの回答ログ、クイズ内の保存状態、出題モード、自動送り設定は追加のlocalStorageへ永続保存します。Googleログイン、Supabaseによる端末間同期、Cloudflareへの公開、教材の予約配信は未実装です。

## クイズセッション

最大10問。誤答・SKIPした語を優先し、次に未回答の語を出題します。前回のモードで即開始し、設定メニューのモード変更は次のセットから反映します。自動送りON/OFFはその場で反映します。

正解は700ms後に次へ進み、誤答・SKIPは意味・例文・英英定義を表示します。結果から誤答のみの再挑戦、次セット、ホームへの移動ができます。キーボードは1〜4、Enter/Space、Escに対応します。

回答ログは語ID・モード・正誤・SKIP・回答日時・セッションID・選択番号を持ち、モード別成績はログから算出します。既存のデータ構造は変更していません。結果の所要時間はセッションの経過時間であり、学習時間の集計には加算しません。

表示確認用の30語は `materials/development-vocabulary.js` に独立して収録しています。教材ID・版・種別・出典・確認情報・公開管理情報を持ち、`environment: development`、`publishedAt: null` によって本番教材と区別します。

検証は `node --test tests/quiz-core.test.cjs`。受入結果と画像は [docs/quiz-session-acceptance.md](docs/quiz-session-acceptance.md) を参照してください。

学習記録の初期データは2026年10月3日時点の表示確認用です。掲載教材は辞書の語義に基づく自作の短い表現解説で、出典は本文に表示しています。事実に基づくニュース教材の登録は今後の工程です。

音声の声質と利用可否はブラウザ・OSに依存します。日本語フォントはGoogle Fontsから読み込み、利用できない場合は端末のフォントへ切り替わります。

合意したアプリ要件は [docs/requirements.md](docs/requirements.md) を参照してください。
